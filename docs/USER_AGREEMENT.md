## 1. 性质说明

本工具是基于开源模型 **VOSR2**（CVPR 2026，Apache-2.0）构建的第三方社区工具，
与 VOSR 论文作者所在机构（香港理工大学 / OPPO 研究院）无隶属、赞助或官方合作
关系。模型权重仅从官方来源（HuggingFace `CSWRY/VOSR`、ModelScope
`LULALULALU/VOSR_CKPT`）获取。

## 2. 生成式超分的固有局限

VOSR2 为**生成式**模型：输出中可能包含输入图像并不支持的"合理"细节。输出不应
被视为对输入中缺失信息的忠实还原，亦不可作为取证证据。对文字密集的图像（路牌、
UI、文档），生成式超分可能"重写"已清晰的小字，请自行评估可读性风险。
