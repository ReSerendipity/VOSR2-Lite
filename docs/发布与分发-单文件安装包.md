# 发布与分发：单文件安装包 + 环境/模型自助下载

> 2026-10-31 定案。此前安装包采用「Setup.exe + VOSR2Lite-Data.7z.001（+ 后续分卷）」的
> 多文件形态，用户需要同时下载并放在同一目录才能安装。瘦包（slim）方案落地后，安装包
> 已**完全不带 torch 运行时与模型权重**，体积大幅下降，因此即日起改为**单文件安装包**，
> 与市面主流桌面软件的发布形态一致。

## 一、发布物形态（GitHub Release）

- **只发布一个文件**：`VOSR2Lite-Setup-v0.2.1.exe`，数据卷（7z 分卷）已通过 NSIS `File` 指令
  **内嵌进安装器本体**，安装时自动解压，不再需要随身携带任何 `-Data.7z.001` 分卷。
- **校验物为强制项（不再是建议）**：同一批次必须带 `SHA256SUMS.txt` 与
  `VOSR2Lite-Setup-v0.2.1.exe.provenance.json`；出包脚本（`scripts/installer/build_setup.ps1`）
  在最后一步自校验，不自洽直接失败退出。构建与校验流程见
  [`安装包构建与溯源.md`](安装包构建与溯源.md)。
- **不再发布的内容**：torch 运行时环境包、模型权重、以及任何大体积分卷。这些内容
  从本版本起**退出 Release 分发范围**（环境包仅保留在 `runtime-v1` 标签作离线路径）。

## 二、环境与模型：用户自助下载

安装包只包含「壳 + 应用代码 + 引导解释器（无 torch）」。首次启动进入
「下载管理（/downloads）」，由用户按页面引导自助完成：

1. **安装运行环境**：默认**在线安装**——后端子进程 pip 直连官方 cu128 索引装 torch 家族
   与生态包（`app/downloads_catalog.json` 的 `install_mode=online`），装进安装目录的
   `bootstrap/` 自身 site-packages，不污染全局；分卷离线路径保留（把 `install_mode`
   切回非 online 即生效）。
2. **下载模型权重**：页面列出所需模型，逐个下载/校验/就位（走官方源，不占本项目带宽）。
3. 完成后按页面提示重启应用，即切换到完整运行形态（Full）。

页面的就绪判据是安装目录下 `bootstrap/RUNTIME.json`（安装流程写入），
不看 `site-packages/torch` 是否存在（WinPython 自带 CPU 版 torch，会误判）。

## 三、构建命令（维护者）

```powershell
# 1) 组装瘦包数据卷（staging + 7z 分卷，产物含 manifest.json / SHA256SUMS.txt）
.\scripts\build_desktop_bundle.ps1 -Mode slim

# 2) 一条命令出单文件安装器 + 校验物（正式出包走这条）
pwsh -File scripts\installer\build_setup.ps1 `
  -DataVolume <第 1 步产出的 VOSR2Lite-Data.7z.001> `
  -ShellExe   scripts\installer\VOSR2Lite.exe
#    脚本内做：版本一致性 → 输入存在性 → 脏树拒绝（-AllowDirty 可强行）→ makensis
#    → 生成 SHA256SUMS.txt + *.provenance.json → 出包后自校验。
#    详见 docs/安装包构建与溯源.md。
```

> 注：`-DSRC_DATA` 缺省时报 `!error` 直接失败——杜绝产出「缺数据」的空包。

## 四、兼容性说明

- 单文件安装器与旧版「Setup + 分卷」安装方式产出的安装目录布局完全一致，
  升级安装无需卸载旧版（安装器会覆盖同路径文件）。
- 首次启动进入引导态（`bootstrap/`，无 torch），入口自动切到 `/downloads`；装完环境后
  壳靠 `bootstrap/RUNTIME.json` 判定已就绪，入口切回首页。
- 关闭按钮语义不变：最小化到系统托盘（托盘菜单内退出），可在设置中改为直接退出。

## 五、环境包（runtime-v1）：默认在线安装，分卷仅作离线路径

**当前默认口径（2026-11-01 起）**：`app/downloads_catalog.json` 的 `runtime.install_mode = "online"`，
下载页**不再下载 GB 级分卷**，而是让后端子进程 pip 直连官方 cuXXX 索引装 torch 家族
（`index_url` / `pip_extra_index` 由 catalog 给定），用 `PIP_CONFIG_FILE=NUL` 屏蔽用户镜像配置
防止 CPU 版顶包；装完写 `bootstrap/RUNTIME.json`，壳重启即切 Full 形态。

分卷离线路径**保留未删**：把 `install_mode` 切回非 online 即生效。此时资产为
`<Product>-Runtime-<cuda>.zip.001..NNN` + `downloads_catalog.json` + `SHA256SUMS.txt`
（构建：`python scripts/build_runtime_bundle.py --torch ... --torchvision ... --cuda ...`），
下载页按 catalog 的 `base_url`（即该 Release 地址）逐卷下载并校验 SHA256，
再 `pip install --no-index` 离线装入引导解释器。

> `volumes` 为空数组是 online 模式的设计结果，不是缺字段；`size_bytes` 的含义由
> `size_bytes_kind: "installed_footprint"` 标注（安装后磁盘占用估算，非下载体积）。

## 六、2026-11-01 端到端实测结论

四应用均在真机完成「页内点安装 → 下载 → 校验 → 离线装 torch → 重启 Full」全流程
（本地 HTTP 源替代 Release，待上传后即为线上等效路径）。实测 torch/CUDA：
SeedVR2/Image/VOSR2 = 2.10.0+cu128，TTS = 2.5.1+cu124，`cuda_available=True`。

## 七、模型分发口径（2026-11-01 定案）

- **默认只挂官方权重**：catalog.models 的条目一律指向上游官方仓
  （ModelScope 直链 `https://modelscope.cn/models/<org>/<repo>/resolve/master/<path>`，
  HF 走镜像 `https://hf-mirror.com/<org>/<repo>/resolve/main/<path>` —— 本机实测
  huggingface.co 直连不通，hf-mirror 200）。
- **本地/社区调参档不作默认**：如 NSFW FP8、自训 LoRA 等，仅作为可选说明留在文档里，
  由用户自行放置到对应目录；引擎默认值只引用官方文件。
- 官方仓命名须实测确认后再写进清单（本轮 TTS: OpenBMB/VoxCPM2、iic/SenseVoiceSmall、
  iic/speech_zipenhancer_ans_multiloss_16k_base 已验证可匿名下载）。
